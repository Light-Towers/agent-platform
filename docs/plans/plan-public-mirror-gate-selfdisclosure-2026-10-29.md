## 5. "缺文件"必须分级，否则 S1 自己变成新的静默失效

沿用本仓 `check_doc_sync` 的 fail-closed 口径，但按仓库身份分档（判据本地可算、不需网络）：

```
git remote 名单含 `company`      ⇒ 内网仓：键表缺失 = rc=2（枚举失效不等于无需检查）
git remote 名单不含 `company`    ⇒ 公开镜像仓：键表缺失 = 正常，打印 INFO，只跑通用形状
```

理由：公开仓本来就不该带主机特定字面量，对它报红会让公开 CI 永远红（→ 被人关掉，比没有更糟，
这是 `lint_public_mirror` 模块 docstring 自己写的前提）；而内网仓缺键表 = 检测面凭空缩小，必须响。

**残留风险（诚实登记）**：内网新克隆若没配 `company` remote 就又缺键表，会落进"公开档"静默少检。
⇒ 复审触发条件：出现任一"内网工作副本无 `company` remote"的实例，就把该档判据换成更强的信号
（如 `deploy/k8s/` 清单是否含真实网段，或 `.intranet/` 目录是否存在过）。

## 10. 取证口径的四条新盲区（影响本件所有“零命中”类结论；rev `896f966e` 实取）

背后是上一批 §7 自查逐条闭合时踩到的（详取证见 `docs/operations/evidence/2026-10-29-public-mirror-shape-c/readings.md` §8）；3/4 两条是下一批把§8 余下三行“邻域档”逐条闭合时新拓的：

1. **`git grep` 默认只扫已跟踪文件**。同一字面量 `-F "FastAPI+Vue3"`：不带 `--untracked` 得 **rc=1 / 0 命中**，带上得 **3 行**（差的文档本身未入库）。而本件的 `_candidate_lines()` 走的正是 `git grep … <ref>`——对 **镜像只能携带已提交内容**这个用途它是对的，但人拿它去“证现状”时会得出假的“全仓零 X”。⇒ **两者对口径的要求相反：门禁按已提交树取证（应如此），人在工作区复查必带 `--untracked`**。不写清这条，S1 落地后的“零命中”会被读成“文面干净”。
2. **正则的 `.` 被当字面量用**：取数首轮用 `-e .prompt`（未加 `-F`）⇒ `.` 匹任意字符，得到 **803 行 / 190 文件** 的噪声，而本轮正是这个噪声让一条“零引用”断言被误判为成立（后证实该断言**不成立**，HEAD 实有 **9** 个 `.prompt` 文件）。⇒ 含元字符的字面量一律 `-F`；`_COARSE_ERE` 里那些 `\.` 转义是必要的，不是过度防御。

这两条不改变本件的 S1 方案（只改变“拿什么当反证”的写法），故不入 §4 拆步，只登记在这里；§6 的非空转反证表将来实跑时，**每条零命中都要同时报“带/不带 `--untracked` 的两个数”**，否则那条反证本身不可核对。

3. **“仓库里只有 N 处 / 本批终态”这类断言自带过期时间，终点就是自己的下一次编辑**。同一 rev、同一未提交工作区上抓到两例：① `2026-10-28-nl2sql-release/readings.md` 曾写“只存在于本文档（命中 1 处 = 本文件本行）”，而同一批次我给 `nl2sql-release-checklist.md` 加了 `:49` 那条“常见错写法”警示注释后，复取变 **2 行 / 2 文件**；② `plan-web-frontend §11.4` 的“同批必 add 清单（终态）”末列引用边，本轮复取 #2 = **4 文件**（表内只记了 2 个引用者）。⇒ 这类句子必须写成“截至 rev X + 取数时刻”的快照，**不许写“终态”**；否则它会在同一批次内被自己的后续编辑静默推翻。
4. **grep 命令字符串只能答“它出现在哪里”，不能答“它对不对”**。上例 ① 的更正文面里顺手写了“那条命令本身没毛病”，就是被这个混淆放过的：实跑 `Select-String -Path deploy/k8s/00-config.yaml -Pattern '^[A-Z0-9_]+:'` → **0 命中**（同文件的缩进口径 `^  [A-Z][A-Z0-9_]+:` → **21 命中**）⇒ 命令确实错（对目标文件恒不命中），而我那条“更正”把一个本来只对一半的指控改成了全错。⇒ 判“命令有无毛病”必须**对它声明的目标实跑一次**，存在性检索不算反证；而“该不该入库/还在不在”这类存在性问题，才轮到 `git grep` 回答（并按第 1 条报两个数）。
